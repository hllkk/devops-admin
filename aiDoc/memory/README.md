# 记忆层 (memory)

AI 跨会话记忆，分两类。**规则见 `AGENT.MD`「记忆规则」**。

## 结构
- `long-term/`：长期稳定偏好 / 协作方式 / 跨任务约束，**一主题一文件**
- `business/`：每条业务需求，**一需求一文件**
- `project-memory.md`：记忆层说明入口（不承载多条正文）
- `demand-index.md`：业务需求索引

## 规则要点
- 用户提出业务需求 → **必须**新增/更新一条 `business/` 记录 + 更新 `demand-index.md`
- 长期沉淀后再提炼到 `long-term/`
- 索引文件只索引，不写正文；更新只改对应文件，不重写汇总覆盖历史
